# Claims Copilot 5-Minute End-to-End Demo Script

Audience: Business + SIU stakeholders  
Duration: 5:00 hard stop  
Primary case: WC-247 (hero case in today's queue)

## 0:00-0:20 - Set the frame
"In five minutes, I'll show the full loop: prioritized queue, rapid Q&A, automated checklist, autonomous fraud analysis, and a finished dossier ready for escalation."

## 0:20-1:00 - Show queue and pick claim
Action:
1. Open Claims Queue.
2. Keep Today view.
3. Click WC-247 (or top HIGH-risk claim if WC-247 is not first).

Talk track:
"This is the examiner's morning queue. Cases are already ranked by risk, so we start with the highest-impact review first. I'll open WC-247 to show the full workflow."

## 1:00-1:40 - Ask one fast question (quick win)
Action:
1. In chat, click Why Flagged? chip (fastest), or type: Why was this claim flagged? Explain the risk score.

Talk track:
"This is the fastest analyst action: plain-English question, immediate answer tied to risk factors and rules. No report digging, no manual lookup."

Optional 1-line follow-up if response is short:
"Give me the top 3 risk drivers for this claim."

## 1:40-2:40 - Run checklist and explain briefly
Action:
1. Click ▶ Run Full Checklist.
2. Let the 7-step checklist card animate through statuses.

Talk track:
"Now we run an automated workflow through the same steps your examiners follow. In a manual process, they'd open different tools one by one: check eligibility, cross-reference policies, review documents. Here, we run the full checklist in one automated sequence.

This is our standardized 7-step examiner checklist covering eligibility, policy alignment, anomaly detection, document verification, and recommendation output. 

Watch for Step 5—Document Review. This is critical for fraud detection: it uses AI vision to analyze actual document images for tampering indicators, metadata inconsistencies, format anomalies. We're checking 13+ document integrity signals that would take an examiner 15-20 minutes to verify manually. Every document that comes through gets the same forensic-level review, every time."

## 2:40-3:45 - Launch autonomous AI fraud analysis
Action:
1. When checklist completes, click Launch AI Fraud Analysis →.
2. Point at Agent Flow and live event timeline.

Talk track:
"The checklist flagged multiple red flags—this is where an examiner's instinct would say 'something's not right here, we need deeper analysis.' Instead of manually pulling claims history, cross-referencing patterns, and building a case file over hours or days, we launch the autonomous investigation.

Now we shift from copilot to autonomous mode. The system orchestrates investigation steps, evaluates evidence quality, and can loop for more evidence before finalizing. We get transparency logs in real time, so this is explainable, not black-box automation."

If dossier rejection appears:
"This is a quality gate in action: it rejected weak evidence, then loops back to investigate deeper before accepting a final dossier."

## 3:45-4:40 - Show full dossier output
Action:
1. Let auto-navigation open Dossier view, or click View Full Dossier →.
2. Scroll quickly through sections.

Talk track:
"This is the full dossier generated from the workflow: executive summary, evidence trail, rule/policy references, timeline, and recommended action. Instead of writing this manually, the examiner reviews and approves."

## 4:40-5:00 - Close with workflow summary
Talk track:
"That's the complete operating model: queue prioritization, fast analyst Q&A, structured checklist, autonomous deep analysis, and a prosecution-ready dossier. Analysts spend less time assembling evidence and more time making decisions."

---

## Presenter cheatsheet (if time gets tight)
- If running behind at 2:45: shorten checklist explanation to "7-step automated workflow including document forensics" and move to Launch AI Fraud Analysis.
- If running behind at 4:00: show dossier headings only; do not deep-read sections.
- If anything stalls: narrate from visible state and move to summary line above.
